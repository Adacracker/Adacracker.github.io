Apa itu game arcade dan kasual?

Game arcade dan kasual dibuat untuk sesi singkat. Biasanya hanya ada satu aksi sederhana - ketuk, geser, tahan - dan skor yang harus dikalahkan. Di kategori ini ada endless runner, game bola dan pantul, game menumpuk, game heliks dan tower drop, game ritme, game ular, game terbang ala flappy, game mewarnai, dan klasik berbau retro.

Apa yang bikin game-nya bagus?

Game arcade yang hebat langsung terbaca sekilas dan adil saat kamu kalah: kamu selalu bisa melihat rintangan yang menjatuhkanmu. Ronde satu-dua menit, skor tertinggi untuk dikejar, dan game yang perlahan makin cepat adalah yang membuatmu menekan 'main lagi'.

Cara memilih: untuk pemula dan pemain berpengalaman

Hampir semua game arcade ramah pemula, jadi pilih sesuai suasana hati. Untuk yang santai, pilih game mewarnai atau menumpuk; untuk tes refleks, coba runner atau game ritme. Pemain yang suka tantangan bisa cari game dengan target harian atau mode yang lebih sulit. Game-game ini paling cocok untuk HP karena sering hanya butuh satu jari.
