Kebijakan Privasi

Terakhir diperbarui: 3 November 2026

Kebijakan ini menjelaskan apa yang terjadi pada datamu saat kamu memakai Arcade Cabin. Singkatnya: kami sendiri tidak mengumpulkan data pribadi, tetapi penyedia game yang gamenya kami sematkan mungkin melakukannya.

Apa yang kami kumpulkan

Arcade Cabin tidak punya akun, pendaftaran, komentar, atau formulir kontak. Kami tidak menjalankan skrip analitik, iklan, atau media sosial milik kami sendiri. Pilihan tema terang/gelap dan pilihan bahasamu disimpan di penyimpanan lokal browser, hanya di perangkatmu sendiri.

Hosting

Server yang menyajikan halaman kami mungkin menyimpan log teknis berumur pendek (seperti alamat IP, jenis browser, dan halaman yang diminta) demi keamanan dan keandalan. Kami tidak memakai log ini untuk membuat profil pengunjung.

Penyedia game pihak ketiga, iklan, dan cookie

Game di Arcade Cabin disediakan dan dijalankan oleh distributor game pihak ketiga:

  • GamePix (gamepix.com)
  • GameDistribution (gamedistribution.com)
  • GameMonetize (gamemonetize.com)

Saat kamu menekan Main, game dimuat di dalam frame dari server penyedia tersebut. Penyedia dan mitra iklannya mungkin menampilkan iklan sebelum atau selama game dan mungkin memakai cookie, penyimpanan lokal, atau teknologi serupa di dalam frame itu - misalnya untuk mengukur tayangan iklan, membatasi seberapa sering kamu melihat suatu iklan, atau mempersonalisasi iklan jika hukum mengizinkan. Pemrosesan ini dikendalikan oleh penyedia berdasarkan kebijakan privasinya sendiri, dan jika diwajibkan, penyedia akan meminta persetujuanmu di dalam game. Tidak ada yang dimuat dari server game milik penyedia sampai kamu menekan Main; thumbnail game di halaman kami dimuat dari server gambar milik penyedia.

Beberapa tautan (misalnya ke game dari studio kami sendiri) membuka situs web lain yang punya kebijakan privasi sendiri.

Pilihanmu

Kamu bisa memblokir atau menghapus cookie lewat pengaturan browser, dan sebagian besar browser bisa memblokir cookie pihak ketiga sepenuhnya. Game tetap bisa dimainkan, meski sebagian mungkin tidak mengingat progresmu dan iklan bisa jadi kurang relevan.

Anak-anak

Arcade Cabin adalah situs untuk semua kalangan. Kami tidak dengan sengaja mengumpulkan informasi pribadi dari anak-anak. Kalau kamu yakin ada anak yang mengirimkan informasi pribadi kepada kami (misalnya lewat email), hubungi kami dan kami akan menghapusnya.
