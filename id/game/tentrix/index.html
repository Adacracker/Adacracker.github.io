Tentang TenTrix

Mau tantangan buat otak? Kamu bisa main TenTrix, game puzzle dari kategori Puzzle, gratis di browser. Bisa dimainkan di HP, tablet, dan komputer. Di HP, pegang secara tegak: game ini dibuat untuk mode potret.

TenTrix: FAQ

Apakah TenTrix perlu bayar?

Tidak, tanpa biaya sama sekali. TenTrix gratis dimainkan di browser kamu lewat Arcade Cabin. Game ini disediakan oleh GamePix, dan penyedia mungkin menampilkan iklan sebelum atau selama game.

Bisakah TenTrix dimainkan di HP?

Bisa. GamePix mencantumkan TenTrix sebagai game yang ramah ponsel, jadi bisa dimainkan dengan layar sentuh di HP dan tablet, juga di komputer. Game ini dibuat untuk mode potret, jadi pegang HP kamu secara tegak.

Apakah saya perlu mengunduh TenTrix?

Tidak. TenTrix jalan di browser langsung di halaman ini - tekan Main untuk mulai. Tidak ada yang perlu diinstal dan tidak perlu membuat akun.

Siapa yang membuat TenTrix?

TenTrix didistribusikan oleh GamePix, salah satu dari tiga penyedia game yang katalognya dipakai Arcade Cabin. Game ini milik pengembangnya, yang namanya tidak disebutkan di feed katalog GamePix.

Game apa yang mirip dengan TenTrix?

Coba TideRoll: Block Puzzle, Block Drop Escape Puzzle, dan Halloween Tile Tumble. Seperti TenTrix, game-game itu ada di kategori Puzzle kami.
