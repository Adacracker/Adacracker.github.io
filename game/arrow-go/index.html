About Arrow Go

Arrow Go loads straight into this page as a free puzzle game. It is best played on a computer. It is played with the arrow keys and taps.

Arrow Go is a relaxing puzzle game where every move matters! Untangle the arrows and clear the entire board by tapping them in the correct order. Each arrow can move only in its own direction, so make sure its path is clear before you tap. Plan ahead, avoid blocked moves, and remove all the arrows to complete the level!

Why you might like it: Fans of Arrows Disappear and Arrow Out may like this one too, since it shares their “logic” and “block” tags.

How to play Arrow Go

Tap an arrow to make it move in the direction it points.

If another arrow blocks its path, it cannot move.

Remove the arrows in the correct order to untangle the puzzle.

Clear all arrows from the board to complete the level.
