Sling Peak is a tactile physics arcade game where momentum, timing and nerve are everything! Slingshot your critter from peg to peg up an endless vertical course. How to play Sling Peak : Rope Swing Game

Desktop:

Drag & release (mouse) = slingshot launch.

Hold Space/W = charge.

A/D or arrows = aim while charging.

A/D or arrows = steer mid-air.

Hold Shift = slow-mo.

Double-click = activate Shield Stash.

R = retry,.

Esc = pause,.

F = fullscreen. Click = menus & UI.

Mobile:

Drag down & release = launch. Drag mid-air = steer. Drag while attached = reel in. Double-tap = activate Shield Stash. Tap = menus & UI.
