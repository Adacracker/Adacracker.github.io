About Xmas Match 3 Dare

Fancy a brain-teaser? Xmas Match 3 Dare is a puzzle game you can play for free on Arcade Cabin, with nothing to download. It runs on desktop and mobile alike. It is played with the mouse and touch. On a phone, turn it sideways for the wide landscape screen.

Xmas Match 3 Dare is a match 3 game based on turns. Swap the blocks to make linear (Horizontally or vertically) matches of 3 or more similar items. Completing each dare will give you 10 bonus turns and a new dare.
