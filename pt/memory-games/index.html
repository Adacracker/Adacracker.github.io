O que são jogos de memória e de objetos escondidos?

Jogos de memória pedem que você lembre onde as coisas estão - na maioria das vezes virando cartas de duas em duas para achar pares iguais. Os jogos das diferenças mostram duas imagens quase idênticas, e os jogos de objetos escondidos dão uma cena detalhada e uma lista de itens para encontrar.

O que faz um jogo ser bom?

Bons jogos deste grupo usam imagens claras e detalhadas, dão uma dica quando você trava e não dependem de um cronômetro severo. Nos jogos de objetos escondidos, os itens devem estar posicionados com inteligência, mas sempre visíveis de forma justa.

Como escolher: iniciantes e jogadores experientes

Para crianças pequenas, comece com jogos da memória de cartas com poucos pares. Adultos vão gostar dos jogos de objetos escondidos e de diferenças com muitas fases. Esses jogos são calmos e uma boa escolha para o tablet.
