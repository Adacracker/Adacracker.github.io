O que são jogos novos?

Os jogos novos são ordenados pela data de lançamento publicada pelos nossos provedores, do mais novo para o mais antigo. Quando um provedor não informa a data, usamos a ordem do próprio feed dele. Os lançamentos recentes são um bom lugar para achar algo que ninguém da sua turma ou do seu trabalho jogou ainda.

Destaques e por quê

  • Color Blocks - Strategically drag and drop blocks to fill grids, clearing columns or rows without leaving gaps. (bom para toque, vertical)
  • Space Miner - Perfect your timing and make precise decisions to achieve targets in increasingly challenging levels. (bom para toque)
  • Ocean Crash - Navigate and align vibrant sea creatures using intuitive controls to set them free. (bom para toque, vertical)
  • Skate Xmas - Navigate your board with precision, leaping between buildings while dodging airborne obstacles. (bom para toque)

Jogos Novos: perguntas e respostas

Com que frequência novos jogos são adicionados?

Sempre que reconstruímos o catálogo a partir dos feeds dos provedores, os jogos novos que passam pelas nossas verificações de qualidade e segurança são adicionados aqui.

Os jogos novos são grátis?

Sim, todo jogo novo é grátis para jogar no navegador.
