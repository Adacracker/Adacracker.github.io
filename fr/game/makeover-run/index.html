Makeover Run : FAQ

Peut-on jouer à Makeover Run gratuitement ?

Oui. Tu peux jouer à Makeover Run gratuitement dans ton navigateur sur Arcade Cabin. Le jeu est fourni par GamePix, et le fournisseur peut afficher des publicités avant ou pendant la partie.

Est-ce que Makeover Run fonctionne sur mobile ?

Oui. GamePix indique que Makeover Run est compatible mobile : le jeu fonctionne en tactile sur téléphone et tablette, comme sur ordinateur.

Faut-il installer quelque chose pour jouer à Makeover Run ?

Non. Makeover Run se lance dans ton navigateur, directement sur cette page - appuie sur Jouer pour commencer. Il n’y a rien à installer et aucun compte à créer.

Qui a créé Makeover Run ?

Makeover Run est distribué par GamePix, l’un des trois fournisseurs de jeux dont Arcade Cabin utilise les catalogues. Le jeu appartient à son développeur, qui n’est pas nommé dans le flux du catalogue de GamePix.

À quoi jouer après Makeover Run ?

Essaie Jenni Styles, Dressup Wheel et Fashion Show Dressup. Comme Makeover Run, ils font partie de notre catégorie Habillage.
